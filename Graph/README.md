## Dijkstra

[アルゴリズムと前提](../Document/dijkstra.md)・[使用例](../Examples/dijkstra_example.cpp)を参照してください。
辺の重みは`[0, 1e9]`です。終点までの経路を求める呼び出しでも、全頂点の最短距離を計算します。
