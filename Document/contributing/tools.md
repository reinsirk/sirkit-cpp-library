# ClaudeとCodexの利用

## 作業の分担と表記

- 有益な場合はサブエージェントへの委任・並列作業を活用する。
- 説明やコメントでは、開発支援に使うツールを「Claude」「Codex」と表記する。コマンド・識別子・モデルの引数には実際の名称を使う。
- 依頼された範囲に従う。読み取り専用のレビューでは、元ファイルの編集と提出を行わない。

## Claudeの起動と利用枠

- Claudeの起動は`Scripts/claude_atcoder.py`を経由する。`CLAUDE_CONFIG_DIR`はリポジトリ内のGit管理外の`.claude-code/`を使う。作業環境ごとの許可済みアカウントはGit管理外のローカル設定または環境変数で指定し、メールアドレスを共有ファイルや実行ログに記載しない。モデルを呼ぶ前に毎回`claude auth status --json`でログイン先を確認し、許可済みアカウントと一致しなければ停止する。普段使いの保存先へ自動で切り替えない。
- Claudeは利用者が確認したログイン先だけを使い、Opus 5.5・Max（`--model claude-opus-5-5 --effort max`）を明示する。Fableの使用は禁止し、利用できない場合も別モデルへ自動で切り替えない。5時間枠・週間枠を確認し、既存結果を再利用して重複実行を抑える。上限に達したらClaude実行を止め、追加課金・無料リセット・別アカウントへの切り替えは行わない。
- 初回設定と起動方法は[開発とVerify](../development.md#claudeの設定)を参照する。作業環境に`.sirkit-local/AGENTS.md`がある場合は、そこで指定されたローカル設定も確認する。
