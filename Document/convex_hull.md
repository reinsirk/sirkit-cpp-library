# 凸包

`Geometry/Polygon.cpp`と全機能版`Geometry/geometory.cpp`に収録しています。
従来の`geo::convex_hull(points, eps)`は点列を値で受け取り、辞書順最小点を先頭とする反時計回りの凸包を返します。完全一致する点と辺上の中間点を除き、空列は空、一点は一点、一直線上の点列は両端だけを返します。

`convex_hull_sorted(points, eps)`は辞書順整列済みの点列を受け取る追加APIで、グローバル名前空間にあります。重複を含めても構いません。既定では通常の走査に組み込んで整列順を検査し、未整列なら`std::invalid_argument`を送出します。`SKIP_RUNTIME_CHECKS`を定義するとこの検査を除き、整列済みが前提になります。

## 方式と計算量

点列を辞書順に並べ、下側と上側の鎖を順に作る単調鎖法です。左折にならない末尾を取り除き、各点の追加・削除は各鎖で一度ずつです。通常版は最悪O(N log N)、整列済み版はO(N)、追加領域はO(N)です。

64ビット以下の整数座標で計算型が十分に広い場合、範囲集計の走査中に整列済みかも調べます。整列済みなら通常版でも並べ替えを省きます。未整列の2048点以上で、x・yそれぞれの最大値と最小値の差が32ビット符号なし整数に収まる場合は、その最小値からの差を一つの64ビットキーに詰め、8ビットずつ安定な基数整列を行います。全キーで同じバイトは処理を省きます。その他は`std::sort`を使います。

基数整列ではキー配列の領域を先に確保します。16384点以上かつ変化するバイトが6個以上なら、全桁の度数を一走査で数えます。32ビットの度数表に収まらない点数では、桁ごとに`std::size_t`で数える経路を使います。整列したキーの重複を除いてから座標へ戻し、同一点の復元を省きます。

## 整数演算と実数の許容誤差

座標の絶対値ではなく差の範囲を使うため、整数上端付近へ平行移動した点群にも対応します。x・yの差とその積が`std::int64_t`に収まる場合、外積の二つの積を64ビットで直接比較します。積同士の減算は不要です。条件を満たさない場合は指定された計算型Cを使います。

整数では、利用する差・積・外積などがCに収まることが前提です。既定のCはGCC/Clangの128ビット整数拡張が利用できればその型、利用できなければ`std::int64_t`です。`SIRKIT_FORCE_STANDARD_ARITHMETIC`または既存の`GEO_DISABLE_INT128`で標準型の経路を選べます。基数整列と64ビットの高速経路は標準C++23だけで動きます。

浮動小数点では従来どおり`orientation`と`Epsilon`で向きを判定します。座標は有限、許容誤差のabs/relは非負有限が前提で、全座標を検査する専用走査は行いません。

## 使用例と検証

```cpp
std::vector<geo::PointI> points{{0, 0}, {4, 0}, {0, 3}, {1, 1}};
auto hull = geo::convex_hull(points);
std::sort(points.begin(), points.end());
auto same_hull = convex_hull_sorted(std::move(points));
```

全機能版の使用例は`Examples/geometry_example.cpp`、提出先はLibrary Checkerの[Static Convex Hull](https://judge.yosupo.jp/problem/static_convex_hull)です。速度測定の条件・結果と独立参照による検査は`Audit/`を参照してください。
