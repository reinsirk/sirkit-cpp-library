# 点とベクトル

`Geometry/Point.cpp`を貼り付けて使います。公開型と関数は`geo`内にあります。直線・線分・多角形・円の各ファイルにも、同じ部品が共有ガード付きで含まれます。

`geo::Point<T,C=geo::DefaultCalc<T>>`は`x`と`y`を持つ集成体です。`T`は符号付き整数または浮動小数点、`C`は内積・外積などの計算型です。別名は次のとおりです。

| 型 | 座標型 |
| --- | --- |
| `PointI` | `std::int64_t` |
| `PointD` | `double` |
| `PointLD`、`RealPoint` | `long double` |

`Point::Value`は`T`、`Calc`は`C`です。距離などの戻り値に使う`Real`は、浮動小数点座標なら`T`、整数座標なら`long double`です。

GCC/Clangで128ビット整数拡張が利用できる場合、整数の既定計算型には拡張型を使います。標準C++の型ではありません。`SIRKIT_FORCE_STANDARD_ARITHMETIC`または従来の`GEO_DISABLE_INT128`を定義すると、整数の既定計算型は`std::int64_t`になります。浮動小数点の既定計算型は`T`です。

## 演算

各操作はO(1)です。座標と入力は有限で、実際に行う座標演算の結果が`T`、差・積・和が`C`に収まることを前提とします。整数全域であらゆる演算が安全になるという意味ではありません。

- `==`と`!=`は座標の完全一致、大小比較は`x,y`の辞書順です。
- `+`、`-`、単項`-`、スカラーとの`*`と複合代入は、座標を演算します。整数座標への浮動小数点スカラーの乗算は使えません。
- `dot(p)`または点同士の`*`は内積、`cross(p)`または`^`は外積です。`norm2()`は長さの二乗、`dist2(p)`は距離の二乗です。戻り値は`C`です。
- `norm()`、`dist(p)`は長さと距離を`Real`で返します。自由関数`distance(a,b)`も2点間の距離です。
- `orient(b,c)`は自分を始点とする2本のベクトルの外積、`ccw(b,c)`はその符号を返します。許容誤差を使う三点の判定は[三点の向き](geometry_orientation.md)を参照してください。
- `rotated90(k)`は反時計回りに90度の`k`倍回したコピー、`rot90(k)`は自身を更新します。既定値は`k=1`で、負数も使えます。
- `arg()`は`atan2(y,x)`の偏角をラジアンで返します。`cast<U,D>()`は座標型を変換し、`to_real(p)`は`long double`座標へ変換します。変換先の型の範囲も利用側で満たしてください。
- `arg_cmp(a,b)`は零ベクトルを先頭とし、+xから反時計回りの偏角と距離で比較します。浮動小数点では丸めた偏角キーが等しいときに距離を比較します。`ostream`出力は`(x,y)`です。

浮動小数点座標では、非零スカラーの`/`・`/=`、ラジアン回転の`rotated(angle)`・`rot(angle)`、非零ベクトルの単位化`normalized()`も使えます。零除算と零ベクトルの単位化は検査省略時も拒否します。`SKIP_RUNTIME_CHECKS`は`normalized()`の有限入力の検査を除きますが、入力の前提は変わりません。

## 許容誤差

`Epsilon{abs,rel}`は絶対・相対許容幅を持ち、既定値はどちらも`1e-12L`です。両方に非負の有限値を指定します。`tolerance(scale)`は`abs + rel * |scale|`を返します。

`almost_equal(p,eps)`は浮動小数点座標を成分別に比較します。`predicate_sign<T,C>(value,scale,eps)`は整数では厳密に、浮動小数点では許容幅を用いて-1/0/1を返します。完全一致による点の比較と許容誤差の比較は別の操作です。

```cpp
geo::PointI a{3, 4}, b{0, 0};
auto squared = a.dist2(b); // 25、計算型C
long double length = a.norm(); // 5
geo::RealPoint unit = geo::RealPoint{3, 4}.normalized();
```
