# 行列の回転と反転

`Algorithm/rotate.cpp` は矩形の `vector<vector<T>>` と文字盤面の `vector<string>` に対応する。コピー版は入力を変更せず、独立した所有権を持つ行列を返す。`T` はコピー構築可能であればよく、既定構築・代入できない型も扱える。

| 操作 | 結果 |
|---|---|
| `rotate_90r(a)` / `rotate_90l(a)` | 時計回り / 反時計回りに90度回転 |
| `rotate_180(a)` | 180度回転 |
| `rotate_quarter(a, turns)` | 時計回りの回数を4で正規化して回転。負数や `INT_MIN` も可 |
| `transpose(a)` | 転置 |
| `flip_i(a)` / `flip_j(a)` | 上下 / 左右反転のコピー |
| `flip_i_inplace(a)` / `flip_j_inplace(a)` | 行列自体を上下 / 左右反転。戻り値なし |

H行W列のコピー版は、要素のコピーをO(1)としてO(H+HW)時間・返却値にO(H+HW)領域を使う。上下の直接反転は行の交換のみでO(H)時間・追加O(1)、左右の直接反転はO(H+HW)時間・追加O(1)で、要素の交換が可能であることを前提とする。

回転・転置の標準経路では、単純型の大きい行列を32角の部分行列に分けて書き込む。小さい行列と縦長行列では出力行の長さを先に確定して追加時の分岐を省き、背の低い横長行列では出力行を順に構築する。非単純型はコピー構築だけで出力を作る。標準経路は専用のCPU命令を必要としない。

入力は矩形が前提。通常処理で参照する行の幅を確認し、`SKIP_RUNTIME_CHECKS` で検査を除く。幅0の回転・転置は先頭以外の行を見ず、上下の直接反転は奇数行数の中央行を見ないため、その部分まで検査する保証はない。コピー版で例外が出ても入力は不変で、直接反転は例外までの変更が残る場合がある。

外側が空の入力に対して、既存の `rotate_90r`・`flip_i`・`flip_j` は互換性のため1本の空行を返す。それ以外のコピー版は空を返す。H本の空行は90度回転・転置で空になり、反転・180度回転ではH本の空行を維持する。

[使用例](../Examples/matrix_transform_example.cpp)と[独立参照テスト](../Verify/current/tests/matrix_reference_test.cpp)を参照。

## SIMD経路

GCC／Clangのx86系でAVX2に対応するCPUなら、コピー・初期化・代入が自明な4・8バイトの算術型・列挙型に、それぞれ8×8・4×4の転置処理を使います。両辺32以上かつ4096要素以上が対象です。独自クラス・文字盤面・bool・それ以外の要素幅・小さい行列は標準の処理を使います。端数の行・列も有効範囲だけを読み書きします。

4バイト要素の32〜64行・8192列以上・524288要素以上の横長行列と、8バイト要素の128列以上の行列では、32列ずつ処理して同じ出力行への書込みをまとめます。8バイト要素の時計回り90度回転は、入力の下側から読み、出力の各行を前向きに書き込みます。4バイト要素も128列以上・1048576要素以上の時計回り回転で同じ走査方向を使い、それ以外の4バイト要素の時計回り回転は入力の上側から読み、出力列を逆向きに埋めます。矩形の検査は最初の列区間で各行を読むときに行い、後の区間では繰り返しません。

`SIRKIT_DISABLE_SIMD`をinclude前に定義すると、専用処理・専用ヘッダー・CPU判定を除きます。`SKIP_RUNTIME_CHECKS`とは独立です。
