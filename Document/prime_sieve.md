# エラトステネスの篩

[実装](../Math/Eratosthenes.cpp)・[使用例](../Examples/eratosthenes_example.cpp)

`PrimeSieve(limit)`は`[0, limit]`の素数判定を奇数1個につき1bitで保持します。構築は`O(limit log log limit)`、保持量は`O(limit)` bitです。

## API

- `limit()`：構築した上限を返します。
- `is_prime(n)`：上限までの素数判定を`O(1)`で返します。
- `prime_count()`：上限以下の素数数を`O(limit/64)`で返します。
- `primes()`：昇順の`vector<uint64_t>`を返します。
- `append_to(result)`：既存のvectorへ素数列を追記します。繰り返し追記するときも通常のvectorの容量拡張を使います。
- `for_each_prime(f)`：昇順に`f(uint64_tの素数)`を呼び、列挙用vectorを作りません。呼出し中に表を変更しないでください。コールバックの例外でも表は変わりません。
- `eratosthenes(limit)`は素数列を返し、`eratosthenes(limit, result)`は既存列へ追記します。

列挙は`O(limit/64+素数数)`です。`primes()`はごく小さい表を除き、個数を先に数えて容量を予約し、再確保とコピーを減らします。
各語の先頭の奇数を128ずつ進め、立っているbitから値を復元します。

コピーは独立した表を作ります。コピー代入は表の複製成功後に上限を更新し、確保失敗時にも元の表と上限を維持します。move元は上限0の空の表になり、代入して再利用できます。

`is_prime()`の上限検査は既定で有効です。`SKIP_RUNTIME_CHECKS`で省略できます。内部の容量・添字の上限は検査省略時も維持します。

## 構築

3・5・7・11の倍数を除いた周期パターンをC++の定数式から生成します。必要な容量を確保してパターンをvectorへ追記し、同じ領域を2度初期化する費用を避けます。この4素数自身は復元します。

1語に収まる上限は、パターンの先頭語から完成した素数表を作ります。127以下の奇合成数は3・5・7・11のいずれかで割れるため、追加の篩は不要です。それより大きい表ではこの事前篩から開始し、13以上の素数の倍数を消します。

さらに大きい表では、平方根以下の基底素数を用意し、基準幅32KiBのブロックごとに倍数を消します。一時領域は基底素数の個数に比例します。

13から127までの素数の倍数は、周期的なANDマスクでまとめて消し、これらの素数自身は最後に復元します。13/17・19/23・29/31・37/41は2素数の積を周期にした共通マスクで同時に消し、配列を通る回数を減らします。それ以外はp語周期のマスクを使います。融合する4組の表は合計3074語（約24KiB）で、全オブジェクトが共有します。

131以上では次の消去位置をブロック間で引き継ぎ、毎回の除算を避けます。1回の反復で4個の倍数を消し、ブロック末尾の端数は1個ずつ処理します。

GCCのx86_64向けでBMI2をコンパイル対象に含めない場合は、消去マスクを`std::rotl`で更新します。各倍数でマスクを作り直す費用を抑えます。BMI2を使う設定とClangなどでは、各位置のマスクを直接作ります。回転は標準C++の処理で、`SIRKIT_DISABLE_SIMD`とは独立です。

ブロック幅は平方根以上にし、任意の上限でもブロックごとの素数走査が計算量を悪化させないようにします。全範囲のビット列を残すため、構築後の単点判定も定数時間です。

## SIMDによる個数集計

AVX2対応環境では、各byteを上下4bitに分けて小さな表でbit数を数えます。8ベクトル分をまとめても1byteあたり最大64なので、byte内で加算した後に64bitの個数へ集計できます。端数は短いベクトル処理と標準のpopcountで処理します。

256語以上では、3本のbit列の和を下位bitと桁上がりに分け、16ベクトル分を1・2・4・8・16の桁へまとめます。16の桁だけを逐次集計し、残る桁は最後に重みを掛けて加えることで、表引きの回数を減らします。256語未満は前述のbyte単位の集計を使います。

小さいビット列と専用処理の対象外の環境では、標準のpopcountを使います。ClangでAVX2がコンパイル対象に含まれる場合も、コンパイラの自動ベクトル化を使います。

環境条件と無効化の指定は[SIMDによる内部処理](simd.md)を参照してください。構築のパターン書き込みに専用SIMDは使いません。

## Verify

[Library Checker提出コード](../Verify/current/submissions/eratosthenes.cpp)はEnumerate Primesを逐次処理します。単点判定、追記、コールバック、所有権、確保失敗、ワードとブロックの境界は独立参照のローカルテストでも確認します。測定条件と検証結果は`Audit/`に置きます。

[境界の補足テスト](../Verify/current/tests/prime_sieve_boundary_test.cpp)では、整数ごとのbyte配列を使う参照篩と照合し、列挙方式の切り替え・桁上がり集計の端数も確認します。
