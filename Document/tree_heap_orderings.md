# 根ごとに木の頂点の並べ方を数える

`tree_heap_orderings(n, edges)` は、各頂点を根にしたとき、すべての親を子より先に並べる頂点順列の個数を求めます。例えば、0 が 1 と 2 に接する木では、0 を根にすると 2 通りで、1 または 2 を根にすると各 1 通りです。

`edges` には 0 始まりの無向木の辺を渡します。戻り値の `counts[r]` は根 `r` での個数です。余りを取る素数は既定で `1000000007` です。第 3 引数で変更する場合は、頂点数より大きい素数を指定します。頂点も辺もなければ空の列を返します。

根を隣の頂点へ移すと、その辺で分かれる二つの頂点集合の大きさから新しい個数が求まります。全頂点分をまとめて求める計算量は `O(n+1)` 時間・領域です。
