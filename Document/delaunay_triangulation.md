# Delaunay三角形分割

平面の整数点から、各三角形の外接円の内部に入力点が入らないように辺を張ります。
返る辺は元の点の 0 始まり添字です。辺の端点は添字の小さい方から並びます。

~~~cpp
using namespace sirkit;
std::vector<DelaunayPoint> points{{0, 0}, {4, 0}, {1, 3}, {1, 1}};
auto edges = delaunay_triangulation(points); // 6本
~~~

同じ座標の点は最小の添字で代表し、すべての点が同一直線上にあれば座標順で隣同士を結びます。
同じ円周上に 4 点以上あって分割が複数ある場合、返るのは条件を満たす分割の一つです。

各軸の `最大座標 - 最小座標` は 20 億以下です。たとえば各座標が `[-10^9, 10^9]` に収まる点を扱えます。
外接円の判定は符号なし 128 ビット整数で行います。構築は `O(N log(N+1))` 時間、`O(N)` 領域です。
構築にはユークリッド最小全域木と共通の分割統治を使います。[Guibas・Stolfi の論文](https://doi.org/10.1145/282918.282923)
