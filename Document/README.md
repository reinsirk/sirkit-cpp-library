# アルゴリズムの説明

各文書に概要、API、短い使用例、重要な前提を記載しています。プログラム全体の使用例は`Examples/`、関数一覧は各ソースの冒頭にあります。

APIは`sirkit`内です。短いコード例ではmain側の`using namespace sirkit;`を前提とし、幾何の`geo`は`sirkit::geo`を指します。
