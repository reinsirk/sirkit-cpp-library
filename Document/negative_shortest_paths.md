# 負辺を含む単一始点最短路

`Graph/Bellman-Ford.cpp` の `BellmanFord` と、`Graph/Bellman-Ford_SFPA.cpp` の `SPFA` は、同じ重み付き隣接リストを受け取る。各ファイルを単独で貼り付けられる。両方を使う場合も `Edge`・`WGraph` と `INF` の共有ガードにより同時に利用できる。

```cpp
WGraph graph(3);
graph[0].emplace_back(1, -2);
graph[1].emplace_back(2, 5);
std::vector<std::int64_t> distance;
const bool negative = BellmanFord(graph, distance, 0);
// negative == false, distance == {0, -2, 3}
```

`BellmanFord(graph, distances, start_index)` と `SPFA(graph, distances, start_index)` は、ともに始点から到達できる負閉路があれば `true` を返す。成功時は出力配列を全頂点分に上書きし、未到達の頂点を `INF`、到達できる負閉路の下流を `-INF` とする。負閉路から戻れない始点や、負閉路とは別の枝には有限距離が残る。未到達成分の負閉路だけでは `true` にならない。

辺重みは `[-1e9, 1e9]`、頂点数は `INT_MAX` 以下。有限の答えは `(-INF, INF)` に入る必要があり、衝突する場合は `std::overflow_error` になる。この有限距離と容量の保護は `SKIP_RUNTIME_CHECKS` を定義した場合も維持する。

既定では始点と、通常の計算中に参照する辺の終点・重みを検査する。未到達頂点の辺は、検査のためだけには走査しない。検査省略時は有効な始点と、参照される辺が上の条件を満たすことを利用側の前提とする。既定の入力検査や計算中の割当で例外になった場合、既存の出力配列を保つ。検査を省く場合は、例外時に古い出力を保つ保証は設けない。

両関数の最悪時間は `O(VE+V+E)`、追加領域は `O(V)`。`BellmanFord` はパスを進めて緩和する方式、`SPFA` は更新された頂点をFIFOキューで再処理する方式を使う。後者も最悪時間が改善するとは限らない。どちらも64頂点以下の補助状態を固定配列に置く。

`BellmanFord` の通常の反復は、出辺を持つ頂点数を S として、高々 `min(V-1,S)` 回に制限する。単純路の各非終端頂点は異なる出辺あり頂点なので、この回数で十分である。出辺を持つ頂点が始点だけなら、閉路は自己辺に限られる。2頂点以上のグラフでは最初の緩和で自己負辺の有無と全終点への距離が確定し、通常の反復を終了できる。

`BellmanFord` は65頂点以上で、始点の出辺が1本で番号が増加する方向へ進む場合、番号順の初回緩和を試す。途中に距離を改善する後退辺がなければ、1回の走査で答えが確定する。途中停止した場合は距離を捨てずに通常処理へ渡す。一本道の到達済み祖先へ戻る改善辺を見つけた場合、その負閉路の下流へ影響を伝播する。大規模で到達部分が小さい場合は、頂点数・辺数を制限した別の経路も使う。これらの試行は最悪計算量の上限を変えない。

通常の反復が長引き、更新頂点が多く減少もしていない場合は、到達部分を非再帰のTarjan法で強連結成分に分ける。成分を縮約したDAGの順に処理し、成分間の緩和は一度、成分内だけ更新頂点の反復を行う。DFS木の祖先へ戻る辺で閉路の重みが負と確定した場合、その成分全体を負影響として扱う。未確定の成分では従来と同じ緩和で負閉路を調べる。最悪時間 `O(VE+V+E)`・追加領域 `O(V)` は維持する。分解時に新たに参照する出辺も、検査有効時はその場で検査する。成分処理が完了した時点で負影響は下流まで伝播しているため、その後の辺の再走査は省く。

最初の分解条件を満たさなかった場合も、64回目に更新頂点数と出辺数から仕事量を調べ、重い反復なら分解を再試行する。少数頂点に多重辺が集中する場合も対象になる。その後も64パスの区切りで、区間の両端のうち少ない方の更新頂点数にパス数を掛けた仕事量を累積する。この見積もりが16Vに達した場合も分解へ移る。候補が一時的に増える場合に反応しすぎず、小さい候補集合が長く反復する場合も再判定できる。予算の更新と判定は区切りで行い、各パスの内側では通常の緩和だけを行う。

成分内では元の順序で最大7回処理し、なお未収束なら更新列を一度反転し、厳密な緩和で使った前駆頂点を記録する。前駆閉路ができれば負閉路と確定できる。検出は緩和回数に応じて行い、Tarjanで使い終えた配列を再利用するため、検出用の大配列や専用の確保を増やさない。

`SPFA` は始点に出辺がない場合、距離配列の初期化だけで終了する。負閉路の影響が見つかるまでは、その伝播用配列を確保しない。負影響を受ける頂点は以後の緩和から除く。キューは同時に入る頂点数が `V` 以下であることを使う。通常はFIFO処理を続け、有効な頂点処理が `min(16V, size_tの最大値)` 回を超える場合だけ、到達部分の強連結成分ごとの処理へ移る。途中までの距離と負影響、検査済み状態を引き継ぎ、未到達成分の出辺は走査しない。切替後は成分間を一度、成分内を必要な回数だけ緩和し、全距離と負影響を確定する。

既存のAPIは全距離と負閉路判定を一度に返すため、同じ処理を重ねる新しい公開APIは設けていない。呼出しごとに内部状態を所有し、入力グラフを変更しない。
