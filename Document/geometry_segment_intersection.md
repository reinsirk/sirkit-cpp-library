# 閉線分の交差判定

`Geometry/Line_Segment.cpp`を貼り付ける。`geo::intersects(s,t,eps)`は端点の接触や区間の重なりを含む交差を返す。零長線分も扱い、時間O(1)、動的確保なし。`geo::intersection(s,t,eps)`は近似交点、または元の座標で辞書順に選んだ重なり区間の両端点を所有する戻り値を返す。

整数の交差判定は、三点の向きで一般交差・端点・共線を分ける。端点や共線の場合は座標範囲を比較し、同じ向きや線分上の述語を重複して評価しない。浮動小数点座標には、許容幅を使う従来の判定を適用する。

座標型と計算型がともに整数なら、共線が確定した後の区間確認には変化する1軸だけを使う。両端点が一致する線分では点全体の一致を調べる。非整数の計算型では、丸めによる零判定を厳密な共線とみなさず、両軸の確認を維持する。

座標は有限、差・積等の必要な演算は計算型`C`に収まることが前提。整数の既定計算型と標準代替は三点の向きと共通。許容幅の意味は幾何学的な距離そのものとは異なるため、浮動入力で厳密な交差を保証するものではない。

```cpp
geo::Segment<std::int64_t> a{{0,0}, {4,0}}, b{{2,-1}, {2,1}};
bool hit = geo::intersects(a,b); // true
```

Verifyは[037 - Intersection](https://atcoder.jp/contests/math-and-algorithm/tasks/math_and_algorithm_ah)。零長・浮動座標・返却座標は独立ローカル検査で補う。

`Verify/current/tests/geometry_segment_predicate_test.cpp`では、多倍長整数による媒介変数の比較を独立参照に使う。小格子の全組合せ、端点の交換、零長、整数端、二進有理数の浮動座標を照合する。`geometry_segment_calculation_type_test.cpp`は、整数座標に浮動計算型を指定した場合の両軸確認を検査する。
