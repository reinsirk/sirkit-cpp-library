# SIMDによる内部処理

SIMDは複数の値を同じ命令で処理します。連続領域への加減算・比較・ビット集計に向きます。
添字や次ノードが直前の結果に依存する処理では、並列に処理できる範囲が限られます。

## 対応環境と設定

公開APIは通常の値型・コンテナを受け取ります。SIMDの型は内部だけで使います。
専用処理にはGCC／Clangの拡張を用い、対象外の環境では標準C++23の処理を選びます。
AVX2を使う関数の対象指定はその内部関数に限定し、必要なCPU機能を確認してから呼びます。

```cpp
#define SIRKIT_DISABLE_SIMD
```

ライブラリを貼る前に定義すると、追加のSIMD専用処理とCPU判定を除きます。
標準C++の処理をコンパイラが自動ベクトル化することは妨げません。
`SKIP_RUNTIME_CHECKS`とは独立した設定です。[素数判定](primality.md)で追加するBMI2版とCPUによる選択も除きます。BMI2はスカラー整数命令です。

## 比較と正しさ

比較対象ではmain・入出力・コンパイラ設定・検査設定をそろえます。
通常の`-O2`と、CPU向けの命令を使える`-O2 -march=native`は別条件として扱います。
自動ベクトル化済みの処理も比較対象に含めます。

端数の要素は有効な範囲だけを処理し、配列の末尾より外は読みません。
小規模入力の切り替え費用、整数幅、符号、独自の値型、専用処理を除いた経路も検証します。
測定条件と結果は`Audit/`に置きます。

## 主な対象

| 処理 | 選択条件と標準経路 |
| --- | --- |
| [行列変換](matrix_transform.md) | 自明な4・8バイトの算術型・列挙型、両辺32以上・4096要素以上でAVX2の8×8・4×4転置。文字・bool・他の要素幅・小行列は標準処理。 |
| [Radix Sort](radix_sort.md) | 64ビット型の128要素以上で順序・変動ビットの集計をAVX2化。ヒストグラム・安定な散布・端数処理は共通。 |
| [トポロジカルソート](topological.md) | 4096頂点以上で、辞書順版は初期候補ビット集合をAVX2で構築。通常FIFO版はGCCで初期候補配列を作る。小規模・非対応CPUでは通常の候補登録。 |
| [Rolling Hash](rolling_hash.md) | GCC/Clangの128bit演算経路では、4096文字以上の構築・再構築でAVX2を選択。4接頭辞と必要な4累乗を並列に計算し、累乗再利用時は接頭辞だけを計算する。非対応時は通常のループを使う。 |
| [Floyd–Warshall](floyd_warshall.md) | AVX2で64bit距離を4列ずつ更新。GCCの非負・有限範囲・64頂点以上では全有限の行列を順序保存したビット列へ移して最小値を選ぶ。未接続値があれば変換を戻し通常の更新を使う。 |
| [HashMap](hash_map.md)・[HashSet](hash_set.md) | GCCのSSE2対応x86で、`optional`で要素を保持する反復子の状態走査を16バケットずつ処理。キーそのものは有効な位置だけを読む。 |
| [集合のゼータ変換](zeta_mobius.md) | 64要素以上の組込み整数でAVX2を使い、複数段の更新をまとめる。Mod型・独自型は通常の処理。 |
| [素数篩](prime_sieve.md) | AVX2対応CPUでbit数を集計。256語以上はbitごとの桁上がりをまとめ、それ未満はbyte単位の表引きを使う。小規模・非対応時は標準popcount。ClangのAVX2対象設定では既存の自動ベクトル化を使う。 |

対応条件を満たしても、初回の呼び出しやコード配置で費用が加わる場合があります。単体APIの短縮と、入出力・起動を含む提出全体の時間は分けて比較します。
