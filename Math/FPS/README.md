# 形式的冪級数の生成部品

[Formal_Power_Series.cpp](../Formal_Power_Series.cpp)は単独貼付用の全機能版です。`components`の実装部品と[NTT.cpp](../NTT.cpp)を、`Scripts/generate_formal_power_series.py`でまとめます。部品はプロジェクトと同じCC0-1.0で、生成後の先頭へライセンスと公開API一覧を置きます。

変更後は生成器を実行し、`--check`で同期を確認してください。詳しい使い方は[Document](../../Document/formal_power_series.md)を参照してください。
