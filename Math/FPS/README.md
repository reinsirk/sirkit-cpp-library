# 形式的冪級数の生成部品

[Formal_Power_Series.cpp](../Formal_Power_Series.cpp)は全機能を含み、単独で貼り付けられます。`Scripts/generate_formal_power_series.py`は`components`の実装部品と[NTT.cpp](../NTT.cpp)をまとめ、生成したファイルの先頭にライセンスと公開API一覧を置きます。部品のライセンスはプロジェクトと同じCC0-1.0です。

変更後は生成器を実行し、`--check`で同期を確認してください。詳しい使い方は[Document](../../Document/formal_power_series.md)を参照してください。
