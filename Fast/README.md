# 速度優先ライブラリ

`SKIP_RUNTIME_CHECKS` の対象となる入力検査を生成時に省いています。一部はメモリの解放も省きます。速度の差はライブラリ・入力・処理系によって変わります。

- [コンパイラ共通](Portable)
- [GCC専用](GCC)
- [Clang専用](Clang)
- [MSVC専用](MSVC)

[Source](Source)に専用実装の生成元があります。解放を省く領域や利用条件は各ソースの冒頭に記載しています。

マクロが後続のコードに効くテンプレート、残る検査、ライブラリごとのメモリ管理については[配布版の説明](../Document/fast_variants.md)を参照してください。
